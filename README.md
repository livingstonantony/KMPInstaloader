# KMPInstaloader

[![Discord](https://img.shields.io/badge/Discord-KMPInstaloader-5865F2?logo=discord&logoColor=white)](https://discord.com/channels/1491463417914069105/1491465908512751786) [![Android APK](https://img.shields.io/badge/Download-Android%20APK-3DDC84?logo=android&logoColor=white)](https://github.com/livingstonantony/KMPInstaloader/tree/master/doc/Android_KMP_Instaloader.apk)


Kotlin Multiplatform Instagram media downloader for Android and Desktop.
Download images from public Instagram posts and videos from public Reels.
Built with KMP and Compose Multiplatform, with more platforms and features coming soon.
 

Inspired by the Python [instaloader](https://github.com/instaloader/instaloader) library, this project aims to provide a similar capability for the Kotlin ecosystem, supporting Android, iOS, Desktop, Web, and Server.

> **Note:** This project is in its very initial stages. Currently, it supports downloading only public posts; access to private posts is under development.



## Supported Platforms
- Android
- iOS - Under Development
- Desktop (JVM)
- Web (Kotlin/JS) - Under Development
